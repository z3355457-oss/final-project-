Analytical Limitations
Data Boundaries &
Model Constraints
No machine learning pipeline is perfect. To ensure scientific transparency, we outline specific data boundaries governing our predictions.
⚠
Critical Modeling Context
Tabular passenger records fail to capture real-time physical chaos, cabin structure blocks, and localized access to emergency evacuation resources.
A
Historical Data Gaps
Over 70% of Cabin logs were missing. Granular physical cabin locations relative to boat decks could not be systematically modeled.
B
Lack of Real-Time Context
Missing immediate physical metrics (e.g., swimming capability, deck elevation at collision time, proximity to specific lifeboat stations).
C
Dataset Scope Limitations
The model is 100% optimized for a static 1912 passenger manifest, meaning it cannot automatically generalize to modern maritime security tasks.
